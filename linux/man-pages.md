## Install on minimal Arch

I have installed the `mandoc` package as a manual database.
The command is `man`.

`less` is a default pager, recommended to install it.

I'm using `most` utility for colorful `man` output.

**Fish config file:**

```fish
set -gx MANPAGER most
```

You can also pipe other commands to `most`.

## Usage

Press `H` for help while in `most` pager.
