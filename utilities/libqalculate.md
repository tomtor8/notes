# Command line calculator

[GitHub site](https://github.com/Qalculate/libqalculate)

Install via `sudo pacman -S libqalculate`

## Launch the utility in interactive mode

```bash
qalc
```

Type `exit` to quit the interactive mode.

## Shell mode

You can type `qalc 0xAB to base` and it does the conversion directly in the shell.

## Currency converter

```
400 Eur to $
400 Euro to Dollar
```

## Unit converter

```
120 kmh -> mph
120 kmh to mph
100 pounds to kg or 100 lb to kg
12 dm3 to l
```

## Math

`pi` is 3.14....

## Numbers

```
1976 to roman
# returns: 1976 = MCMLXXVI
255 to hex
# returns: 255 = 0xFF
8 to bin or 8 to base 2
# returns: 8 = 0000 1000
```

### Hexadecimal number to decimal.

```
0xAB to base 10
0xAB to base
```

## Time and date

```
10:35 + 8:48 to time
# 19:23
```
