# Purpose

- TUI music player for terminal
- enables library management

# Installation

- install via `yay -S musikcube-bin`

# Settings

- disable `degrade to 256 color palette` to enable custom themes
- enable `sync metadata on startup`
- enable `remove missing files from library`

# Theming

- custom themes are located in `json` files in the `~/.config/musikcube/themes/` directory
- in the settings then choose the `color theme`
